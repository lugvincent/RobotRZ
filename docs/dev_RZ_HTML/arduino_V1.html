SP SE Tasker VPIV

Arduino Mega + UNO

Contrôleur temps-réel. Gère capteurs et actionneurs physiques. Ne décide rien de haut niveau — SP décide, le Mega exécute. Loop max 80ms, watchdog intégré.

Deux cartes — rôles distincts
Arduino Mega
Maître du sous-système hardware
Gère tous capteurs et actionneurs
Lié à SE par USB-C
Bridge via mqtt_bridge.py (SE)
Firmware C++ / PlatformIO
Loop max 80ms — watchdog intégré
Arduino UNO — esclave moteur
Dédié exclusivement au pilotage PWM moteurs
Reçoit ordres du Mega via UART série
Format : <L,R,A>
Invisible depuis SE et SP
Driver : Pololu Dual VNH5019
Freine auto si silence Mega > 1000ms
Architecture firmware — 3 couches strictes (chaque module)
dispatch_Xxx.cpp — couche VPIV
Reçoit la trame depuis vpiv_dispatch.cpp. Valide les champs. Appelle la couche métier. Envoie ACK via sendInfo() ou sendError().
Xxx.cpp — couche métier
Calculs, décisions, gestion d'état du module. Aucun accès direct au hardware.
xxx_hardware.cpp — couche hardware
Accès direct broches et timers. Isolation complète du hardware.
Chaque module = un namespace avec dispatch(prop, inst, value). Pas de String() — char buf[] + snprintf() uniquement. Pas de float sur le fil VPIV — entiers ×1000. Pas de malloc/new dans la loop.
Capteurs gérés par le Mega
us.cppVAR : US9 capteurs HC-SR04
9 capteurs ultrasons. Distances, alertes anti-collision. Alimente mvt_safe.cpp pour la sécurité mouvement automatique.
mic.cppVAR : Mic3 microphones
Niveau sonore moyen, angle de provenance du son (0-180° en degrés×10), détection présence. Distinct du microphone SE géré par rz_microSe_manager.sh.
mvt_ir.cppVAR : IRmvtDétecteur IR
Détection mouvement infrarouge. Seuil configurable, fréquence de détection.
fs.cppVAR : FSCapteur force
Valeur brute et force calibrée. Alerte seuil. Utilisé par ctrl_L.cpp pour le pilotage par laisse (typePtge=3 et 4).
odom.cppVAR : OdomOdométrie
Position x/y (m×1000), cap calculé. Reçoit gz depuis Gyro SE — ce relai est obligatoire, SP extrait la valeur et la publie vers Arduino. Fréquence et coefficient roue configurables.
⚠ Le gyroscope (LSM6DS3C) et le magnétomètre (MMC3630KJ) sont sur SE (smartphone), pas sur le Mega. Leurs données arrivent au Mega via SP — c'est un relai explicite, pas une lecture directe.
Actionneurs gérés par le Mega
mtr.cppVAR : MtrMoteurs → UNO
Commande différentielle v/ω → L/R. Scale et kturn en entiers×1000. Envoie format <L,R,A> à l'UNO via UART. Keepalive 100ms obligatoire sinon l'UNO freine automatiquement.
// Format UART vers UNO <L,R,A> // L=vitesse gauche signée (-400..400), R=vitesse droite, A=accélération (0..4)
srv.cppVAR : Srv3 servomoteurs
TGD (tête gauche/droite), THB (haut/bas), BAL (balance). Angles en degrés entiers. Vitesse configurable. PWM 50Hz.
lring.cppVAR : LringAnneau LEDs
Expressions visuelles du robot. Couleur RGB, animations, mode urgence (rouge clignotant). Piloté par Gtion_EtatGlobal via SP.
lrub.cppVAR : LrubRuban LEDs
Couleur, luminosité, effet fuite, timeout automatique. Géré indépendamment de Lring.
mvt_safe.cppVAR : SecMvtSécurité mouvement
Anti-collision basé sur données US. Réduction douce ou arrêt dur selon distances. Fonctionne en autonomie dans la loop — ne dépend pas des commandes SP.
ctrl_L.cpptypePtge 3/4Pilotage laisse
Mode laisse physique. Exploite le capteur force FS. Actif si typePtge = 3 (Laisse) ou 4 (Laisse+Vocal). Traité en étape 4 de la loop.
Ordre de la loop() — non bloquant
1
communication_processInput() — parsing VPIV entrant depuis SE
2
lring / mic / us / fs / mvt_ir / odom — tâches périodiques capteurs
3
mvtsafe_process() — anti-collision basé US
4
ctrl_L_update() — mode laisse (si typePtge = 3 ou 4)
5
lrub_processTimeout() — extinction LED ruban automatique
6
srv_process() — PWM servos 50Hz
7
mtr_processPeriodic() — keepalive <L,R,A> vers UNO toutes les 100ms ⚠ OBLIGATOIRE
8
Watchdog — si loop > 80ms → déclenche URG_LOOP_TOO_SLOW
Gestion des urgences hardware
Les urgences sont toujours déclenchées en interne par le firmware, jamais depuis SP. Quand urg_active = true, toutes les commandes VPIV sont ignorées sauf CfgS:emg et Urg:clear.
Codes urgence Arduino
motor_stall
sensor_fail
buffer_overflow
parsing_error
loop_too_slow
Déblocage urgence
Seul SP peut envoyer :
$V:CfgS:(emg):*:clear#

ou

$V:Urg:clear:*:OK#
Conventions C++ firmware
